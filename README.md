# داشبورد تدارکات فجر انرژی — نسخه PWA (FE MVP 1.0.4)

## انتشار روی GitHub Pages
1. در GitHub یک مخزن (Repository) جدید بسازید.
2. همه فایل‌های این پوشه را (`index.html`، `manifest.webmanifest`، `sw.js` و پوشه `icons`) در ریشه مخزن آپلود کنید (Add file ← Upload files).
3. Settings ← Pages ← Source: «Deploy from a branch» ← Branch: `main` و پوشه `/ (root)` ← Save.
4. بعد از یکی دو دقیقه آدرس `https://<نام‌کاربری>.github.io/<نام‌مخزن>/` فعال می‌شود.

## نصب روی آی‌پد
1. آدرس را در **Safari** باز کنید.
2. دکمه Share ← **Add to Home Screen**.
3. از آیکون ساخته‌شده باز کنید. بعد از اولین بازکردن با اینترنت، برنامه آفلاین هم باز می‌شود.

## کار با داده‌ها روی آی‌پد (حالت مشاهده)
- فایل `negahban.sqlite3` و فایل دیتابیس (مثلاً `FE_Production.sqlite3`) را از برنامه Files انتخاب کنید.
- نسخه‌ای از فایل‌ها روی آی‌پد ذخیره می‌شود و دفعه بعد دوباره انتخاب نمی‌خواهد.
- برای دیدن داده تازه: دکمه «به‌روزرسانی فایل‌ها» ← فایل‌های جدید را انتخاب کنید.
- ثبت و ویرایش فقط روی کامپیوتر (Chrome/Edge) انجام می‌شود.

## به‌روزرسانی برنامه
فایل `index.html` جدید را روی همان نام جایگزین کنید. آی‌پد بعد از یک‌بار بستن و بازکردن برنامه نسخه جدید را می‌گیرد.

## نکته حریم خصوصی
آدرس GitHub Pages عمومی است. خود برنامه (ظاهر، لوگو و نام پروژه) برای هر کسی که آدرس را بداند قابل باز شدن است؛ ولی هیچ دیتابیس و رمزی داخل آن نیست و داده‌ها فقط از فایل‌هایی که شما روی دستگاه انتخاب می‌کنید خوانده می‌شود.
